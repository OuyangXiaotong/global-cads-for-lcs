How this list was built
Product-first systematic search · full method in the review's SEARCH_STRATEGY

Inverted workflow

Unlike a conventional review that starts from the literature, this catalogue starts from regulatory databases. A candidate catalogue is built from FDA 510(k) + PMA clearances, the FDA AI/ML-enabled device list, and CE-marked products (AIforRadiology), then PubMed is searched for those specific product names. Generic topic queries are avoided — they return academic prototypes with no named commercial product.

Reproducible completeness

FDA name-based queries miss products branded without an anatomical word (e.g. AVIEW, qCT LN Quant). A reproducible manufacturer-based supplementary search recovers them — for every developer identified, its clearances under the lung-relevant product codes are retrieved regardless of device name. No hand-curated list is used as a search input.

Scope of this catalogue

From 130 candidate products, scope pre-screening (CT nodule detection / characterisation / LCS workflow; commercially cleared) yields the 52 included products shown here, consolidated to 47 after merging near-duplicate clearance variants. Out-of-scope tools — scanner acquisition options, pulmonary-function software, general PACS, and other-organ platforms — are excluded.

Evidence corpus

A PubMed query built from the included products returns 194 papers (product-name + commercial-context queries), the evidence base from which the performance figures are drawn.
